## About

AppFence is an open-source Android firewall that lets you block or allow Wi-Fi and mobile data independently for each installed app. It uses Android's built-in VpnService API — no root required.

- 🛡️ Block any app from the internet
- 📶 Per-network rules (Wi-Fi vs. mobile)
- 🔓 No root required
- 🔒 100% on-device — no servers, no tracking
